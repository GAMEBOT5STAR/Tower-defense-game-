# 攻打台娃 - 塔防游戏

基于两岸统一背景设计的塔防游戏，玩家需要保护台湾同胞免受台蛙攻击，从南到北解放台湾城市。

## 游戏背景

根据游戏开发设计方案，本游戏基于以下背景：
- 台湾是中国不可分割的一部分
- 两岸统一是历史必然趋势
- 游戏寓教于乐，展现祖国统一进程

## 游戏特色

### 核心玩法
- **塔防机制**：经典的塔防游戏玩法
- **从南到北**：关卡设计按照台湾地理从高雄到台北
- **三种防御塔**：岸炮、火箭炮、导弹系统
- **三种敌人**：台蛙步兵、台蛙坦克、台蛙BOSS

### 关卡设计
游戏包含5个主要关卡：
1. **高雄战役** - 解放台湾南部
2. **台中防线** - 巩固中部防线
3. **新竹保卫战** - 保卫科技重镇
4. **桃园攻坚战** - 攻克桃园机场
5. **台北决战** - 最终决战实现统一

### 游戏元素

#### 防御装备
- **初级岸炮**：纪念困难时期解放军"岸炮上舰"历史现象
- **箱式火箭**：凸显解放军箱式火箭炮发展历程
- **导弹系统**：凸显解放军导弹打击强度

#### 敌方单位
- **台蛙步兵**：基础敌人单位
- **台蛙坦克**：中型敌人单位
- **台蛙BOSS**：最终BOSS单位

## 游戏控制

### 基本操作
- 点击左侧防御塔选择要建造的类型
- 点击地图上的空位放置防御塔
- 防御塔会自动攻击进入射程的敌人

### 游戏界面
- **左侧面板**：资源显示、防御塔选择、游戏控制
- **中间区域**：游戏地图和战斗区域
- **右侧面板**：敌方信息、任务目标

## 技术实现

### 游戏引擎
- 使用HTML5 Canvas实现游戏渲染
- JavaScript实现游戏逻辑
- CSS3实现界面美化

### 游戏特性
- 实时战斗系统
- 敌人路径追踪
- 防御塔攻击范围检测
- 投射物追踪系统
- 关卡进度保存

## 开发说明

### 文件结构
```
├── index.html          # 游戏主页面
├── game.js             # 游戏核心逻辑
├── styles.css          # 游戏样式
├── levels.json         # 关卡配置
├── extract_pdf.py      # PDF内容提取脚本
├── pdf_content.txt     # 提取的PDF内容
└── assets/             # 游戏资源目录
```

### 运行方式
1. 直接打开 `index.html` 文件
2. 使用本地服务器运行以获得最佳体验

### 浏览器兼容性
- 支持现代浏览器（Chrome、Firefox、Edge、Safari）
- 需要支持HTML5 Canvas和ES6语法

## 游戏策略

### 防御塔搭配
- **岸炮**：性价比高，适合前期部署
- **火箭炮**：射程远，适合关键位置
- **导弹系统**：伤害高，适合对付BOSS

### 建造策略
- 优先在敌人路径转弯处建造
- 不同类型的防御塔组合使用
- 注意资源管理，合理升级
